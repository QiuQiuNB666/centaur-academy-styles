半人马AI学院 · 美术范式候选

同一份首页文案、同一批插画，六种美术范式。每套都有完整的 DESIGN.md（色板、字体、间距、组件、Do / Don't、Agent Prompt Guide）、可滚动的首页预览和一页组件样张。当前完成 6 / 6。

横向评审的看法（独立评委 agent，仅供参考，你说了算）

我看了六套的首屏、整页切片和手机端对比，建议这样选。

  • 想稳： 选 04「董事会深蓝」。它对经营者和管理者最对味，字也最大；但要接受它长得像商学院，建议把首屏罗盘做得更独特，把黄铜小字加粗加深。
  • 想被记住： 选 06「折纸色块」。它是唯一从自家 logo 长出来、别家抄不走的方案，代价是要降饱和，并重配插画。
  • 更折中： 用 04 或 01 的骨架，只移植 06 的经折五步带和折角卡片，做局部点睛。
  • 02「墨与印」： 辨识度最高，但会把学院带向国学方向；除非站主明确要走东方人文路线，否则不建议。
  • 03 和 05： 是给设计师和技术人看的，和目标人群错位。
  • 01、03、04： 这三套同质化明显，终选名单里留一套就够。

评审排序：董事会深蓝 → 纸上学刊 → 折纸色块 → 墨与印 → 瑞士网格 → 夜航精密

纸上学刊

两种纸，一种墨，一种专色，线比色块重要

  • #f2efe7
  • #fcf8f0
  • #1c1b18
  • #1b4bb0
  • #d3cdbf

记忆点文武线刊头 + 贯穿全页的 200px 页边栏（章节号、栏目名、与图底对齐的图注都进页边，一根细栏线从头贯到尾），强调词下点钴蓝着重号，文章封面一律钴蓝专色单印。

字体Noto Serif SC 思源宋体（回退 Songti SC）500/700/900 / Noto Sans SC 思源黑体（回退 PingFang SC、微软雅黑；拉丁 Helvetica Neue） / Newsreader（拉丁字、数字、眉标、箭头；回退 Iowan Old Style、Georgia），等宽仅 kit 页用 ui-monospace

锚点Anthropic · Stripe Press · The New Yorker · Monocle · 单向空间 owspace

适合适合把学院定位成长期出观点、出文章的思想型机构，靠内容和院长来信建立信任。暖纸黑墨、衬线大标题对中年读者友好，钴蓝单印封面让文章列表很统一。

代价整体偏安静，首屏半人马装在相框里，冲击力最弱。作为签名的 200px 页边栏在手机上整个消失，微信里看起来就是一张普通的杂志风页面；页边的图注和栏目字很小；以后每张文章封面都要做钴蓝单色处理。

瑞士网格

白底、近黑、一支钴蓝，全部落在 12 栏上

  • #ffffff
  • #141414
  • #0f5fd0
  • #0b4fc0
  • #5c5f66

记忆点常显的 12 栏发丝竖线 + 页眉的「网格钮」（纯 CSS checkbox）：按一下整页的栏以 7% 钴蓝显形，证明每个字每张图都对在栏上；配合第 1–2 栏的悬挂编号、踩在 6px 黑色「地面线」上的彩色半人马，以及全部转为单色图版的插画。

字体思源黑体 Noto Sans SC 900 + Archivo 900（标题，回退 PingFang SC / Helvetica Neue） / Noto Sans SC 400 + Archivo 400（正文） / Archivo 500 tabular-nums 做悬挂编号与日期，Geist Mono 仅用于样张里的 hex 与 token 名

锚点Pentagram · MIT Media Lab · teenage engineering · Vercel Geist · IDEO U · Josef Müller-Brockmann《Grid Systems》

适合适合把学院讲成方法论加工具型品牌，面向设计、产品或偏理性的年轻管理者；信息层级最清楚，手机端也最干净。

代价「网格钮」是设计师才懂的梗，企业主不会去按，也不在乎。插画全转黑白后原本的温度没了，整页偏冷，少了「人」的感觉；粗黑体配钴蓝在设计工作室和科技公司官网里很常见；悬挂小标签的字号偏小。

适合最贴合 35–55 岁企业主和高管：深蓝、象牙、衬线大字沉稳可信；罗盘和指针把「人决定方向」画了出来；暖色插画放在象牙底上很协调，正文字号在六套里最大。

代价深蓝配金是 EMBA、商学院、财富管理、律所的通用配色，最容易被当成「又一家商学院」，辨识度基本只靠首屏罗盘。黄铜小字和空心数字偏细偏淡；首屏实际是深色，在微信里第一眼偏沉；页面也偏长。

折纸色块

把 logo 的折纸切面铺成整站的色块

  • #f6f1e6
  • #1450c8
  • #f47216
  • #0e1a3a

记忆点每种品牌色都有受光、本色、背光三个面。半人马抠图站在橘橙折纸台座上，身后是斜切的钴蓝大色块；分区之间用斜折痕过渡；「共学五步」做成一条上下沿交替错开的经折流程带；所有容器方正，右上折角，只用不带模糊的硬位移纸影。

字体Bricolage Grotesque 800 + 思源黑体 Noto Sans SC 900（标题） / Noto Sans SC 400·500·700（正文，回退 PingFang SC / Microsoft YaHei） / Space Mono（眉标、图注、日期）

锚点Gumroad · Headspace · Pitch · Mailchimp · Figma

适合适合想让品牌自己被记住、线下活动和海报物料多的路线。视觉全部从 logo 的折纸切面长出来，别家抄不走；经折五步带和折角卡片是六套里最有记忆点的组件；首屏半人马最大、最有气势。

代价大面积高饱和橙蓝整屏铺开，气质偏训练营和互联网活动页，对 50 岁上下的企业主不够沉稳，长页读下来眼睛累。现有低饱和暖色插画压在亮橙亮蓝上明显打架，多半要重画或重新调色。页面是六套里最长的，子页面也很难一直维持这个强度。
