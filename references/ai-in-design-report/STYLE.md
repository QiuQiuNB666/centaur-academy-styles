# AI in Design Report 2026（Designer Fund × Foundation Capital） — Style Reference
> 把一份行业调研做成一本可滚动的刊物：白纸、黑字、一块橙、一抹紫，数字和句子就是主视觉。

**Theme:** light（白底黑字，暖灰分区，橙/淡紫点色）

整站读起来像杂志而不是落地页：顶栏左上是黑底字标方块，紧挨一条橙色「阅读报告」色条；首屏上半是紫橙渐变的拼贴图（带等宽小标签的矩形切片），下半是 120px 的超紧字距大标题压在白底上，左侧一小段导语，左下一行等宽大写的署名。全站零圆角、零阴影，层次完全靠字号跳变、留白和色块。Framer 搭建（generator: Framer）。

## Typography
- 标题 / 正文：**Beausite Classic**（Medium 500 为主，Regular 400 作正文，Bold 700 作强调），自托管商业字体（Fatype 出品——按字体名判断，源码里未见厂牌声明）。开了 OpenType 替换字形（cv03/cv04/cv09/cv11）。
- 等宽：**Geist Mono**（标签、署名，大写）；少量 Fragment Mono。Inter 仅为 Framer 兜底。
- 首屏 H1：120px / 500 / letter-spacing -0.06em / line-height 95%。
- 章节 H1 预设：50px（桌面）→ 40px → 32px（<900px），-0.04em，行高 1em。
- 大引语/大数字段：50px → 32px → 24–26px，-0.03em，120%；另有 80px / -0.06em 的展示级。
- 正文 16px / 400 / -0.01em / 1.4em；小字 13–15px；等宽标签 12–14px。
- 规律：字越大字距越紧（-0.01 → -0.03 → -0.04 → -0.06em），行高越贴（140% → 120% → 100% → 95%）。

## Shapes & Motion
- 圆角：显式值只有 `0px`，全站直角。阴影：未读到任何自定义 box-shadow。
- 线：1px 白/黑细框圈住图像切片；标签是贴边的小白块 + 等宽字。
- 栅格：断点 900 / 1440 / 1920 / 2560；首屏为左窄右宽的不对称两栏（导语在左 1/4，标题从约 42% 处起）；页边距约 16px，很贴边。
- 动效：Framer tween，曲线 `cubic-bezier(0.44,0,0.37,1)`；链接 hover 0.2s `cubic-bezier(.44,0,.56,1)`。具体时长/滚动计数实现未能从静态源码读到。

## Signature（签名手法）
1. **顶栏即色块**：黑方块字标 + 橙色满高 CTA 条 + 右侧纯文字导航带「+」号，导航本身像刊物书脊。
2. **120px 超紧标题压白底**：-0.06em、95% 行高、500 字重，不加粗不加色，靠尺寸取胜。
3. **等宽大写小标签**：Geist Mono 做署名、角色标签、章节编号，与大号无衬线形成「刊物 + 档案」的对照。
4. **图像只有一种处理**：紫橙热力渐变 + 颗粒 + 矩形切片拼贴，一套滤镜贯穿，不靠摄影质量。
5. **零圆角零阴影**，分区靠 #f7f6f4 暖灰与白交替。

## 迁移到半人马AI学院
- **借什么**：不对称首屏（左导语右大标题）、色块顶栏、「大数字 + 等宽标签 + 大引语」的章节节奏；三章结构可改写为「主张—三章课程—经营者证言」。橙色 `#fe7141` 与 logo 的橙天然接近，蓝可替掉淡紫做第二色。
- **需要补**：Beausite Classic 需向字体厂购买 Web 授权且无中文；中文要另配一款紧凑黑体（如思源黑体 Medium / 阿里巴巴普惠体等可商用字体）并重调字距——中文不能套 -0.06em，建议 -0.02em 以内。需要真实数字（学员数、企业数、课时）和真实学员引语；首屏拼贴图可用 logo 的低多边形切面做同一套滤镜。
- **风险**：中文大字没有拉丁字母的字形节奏，120px 黑体容易显笨，要靠字重和留白救；没有真实数据时「大数字」会变空洞；直角零阴影对内容质量要求高，文案弱就会显得简陋。
