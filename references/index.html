操刀Bureaux（Webby 参赛方与 FWA Credits 均写明）

它高级在哪

  • 一物到底：全站只有一个 3D 主体（冰屋），滚动即镜头推进，物件经历完整→解体→重组，叙事不靠版块
  • 四角钉字：所有文字缩成 IBM Plex Mono 小字钉在视口四角，用 // 与 ////// 做代码注释式小标题，右栏右对齐成窄柱，中央永远留空给物件
  • 数据标注线：在 3D 物件表面打点、连白色 1px 细线、挂两位数字，把好看的图变成被测量的对象
  • 单色到底加一次暖色：全程冷灰白（#A0A5B1 / #E1E6F1 / #6A6F7D），琥珀色只在一个场景出现一次；连 loading 都是同一套等宽 ASCII 语言

字体全站唯一字体 IBM Plex Mono（IBM 出品，SIL OFL 开源），自托管 woff2，Regular 与 Medium 两个切口；标题/正文/等宽同一套。文字被烘成 MSDF 贴图（IBMPlexMono-Medium-datatexture.ktx2）在 WebGL 画布内绘制，不是 DOM 文本。

字号没有 H1：DOM 的 body 为空，无任何标题元素，首屏最大字就是 logo 字标。源码里唯一读到的 CSS 字号是 font-size:17px + font-family:monospace（降级/提示层）；画布内文本组件 lineHeight 为 .8 或 1；字距未能读到；小字目测 13–15px。

形与动CSS 层面无圆角、无阴影（源码未读到任何 border-radius / box-shadow），体积感全靠 3D 光照、雾与辉光；无栅格，四角钉字、边距目测约 50px、中央留给 3D 主体。动效由 GSAP 驱动，曲线以 sine.out、power2.out、power2.inOut 为主，无自定义 cubic-bezier；加载态是雾灰底上一行 ASCII 进度符。

搬到半人马学院

借首屏结构：3D 半人马居中、滚动时折纸面片展开重组、四角钉小字、用标注线把「人决定方向 / AI 拓展能力」挂到人身与马身上。需要补：半人马的真 3D 模型（glb，只有渲染图做不了，或降级为预渲染序列帧滚动擦洗）、three.js+GSAP 前端能力；IBM Plex Mono 免费可商用但不含中文，需配思源黑体或 IBM Plex Sans SC（均 OFL）。风险：该站冷灰单色与学院橙蓝高饱和 logo 冲突，只能借结构不能借配色；纯画布文字对 SEO、无障碍、微信内置浏览器和低端机不友好，中文正文必须回到 DOM；只适用首屏，课程/报名等长内容页要另配常规范式，且首屏加载重（主包约 1.5MB JS 另加模型贴图）需移动端静态图降级。
